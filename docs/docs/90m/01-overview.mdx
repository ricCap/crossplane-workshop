# 90 minute workshop

:::caution Preview draft
This is the CLI-first workshop in draft. The commands come from the Crossplane CLI v2.5 docs and have not been dry-run end to end yet. Modules 4 to 7 are placeholders.
:::

In 90 minutes you build your own platform API with the [Crossplane CLI](https://docs.crossplane.io/cli/v2.5/), package it, and publish it from your laptop to your workshop cluster. You start from an empty folder and end with a running `WebApp` API that other teams could use.

**What you walk away with:** a Crossplane project you created yourself, a packaged Configuration in a registry, and a working mental model of XRD, Composition, XR, Function, and Package.

## How the 90 minutes split

| Clock | ⏱️ | Block | What you do |
|---|---|---|---|
| 0:00 | 20m | Intro | The problem Crossplane solves, the core objects, and how the next hour works |
| 0:20 | 5m | [Set up the CLI](./set-up-the-cli) | Check Docker, install the CLI, log in to the registry |
| 0:25 | 10m | [Create your project](./create-your-project) | `crossplane project init`, write an example XR, generate the API |
| 0:35 | 15m | [Compose](./compose) | Generate the Composition and a function, fill in the template |
| 0:50 | 8m | [Iterate locally](./iterate-locally) | Render and validate without touching a cluster |
| 0:58 | 12m | [Package and ship](./package-and-ship) | Build, push, and install your package, then apply an XR |
| 1:10 | 7m | [Change and rebuild](./change-and-rebuild) | Edit the template, rebuild, and watch the XR update |
| 1:17 | 3m | Slack | Catch up, or look at a Provider |
| 1:20 | 10m | Outro | What the cluster under you was built from, and where to go next |

## Before you start

You need three things on your laptop:

- A running Docker-compatible container runtime. The CLI uses it to render Compositions and build packages.
- A terminal with `kubectl`.
- The credentials bundle your instructor gave you: a kubeconfig for your workshop cluster, plus the address and login for the workshop registry.

Open the [Cheatsheet](../cheatsheet) in a second tab. It explains every term this workshop uses.
